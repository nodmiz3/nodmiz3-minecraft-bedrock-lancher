# Minecraft Bedrock Launcher
WebView2 を使用した Minecraft Bedrock Edition 用の軽量ランチャーです。  
起動時にスプラッシュ画面を表示し、HTML ベースの UI を読み込んで動作します。

---

## ✨ 特徴
- 起動時スプラッシュ画面（PNG 自動同梱）
- WebView2 による HTML UI 表示
- launcher.html を自由に編集可能
- アイコン（ICO）対応
- Windows Forms ベースで軽量・高速

## 📥 インストール方法
1. Releases から ZIP をダウンロード  
2. 任意のフォルダに展開  
3. `Minecraft Bedrock Launcher.exe` を実行

---

## 🎮 使い方
1. ランチャーを起動するとスプラッシュ画面が表示されます  
2. 2秒後にメインウィンドウが開きます  
3. WebView2 が `launcher.html` を読み込み、UI が表示されます  
4. UI 内のボタンから Minecraft Bedrock Edition を起動できます（必要に応じてカスタム）
